# 会議録テンプレート（確定版）

Cogno notetaker が記録したミーティングを Notion 会議録データベースへ転記する際の
**確定フォーマット**。

---

## Notion プロパティ

| フィールド | 型 | 内容 |
|---|---|---|
| **Title** | title | 会議タイトル |
| **Date** | date（start） | 会議日（ISO形式、例: `2026-08-21`） |
| **Member** | rich_text | 参加者（カンマ区切り、例: `石原俊, 新井康太`） |
| **MEMO** | rich_text | 必要に応じてメモを追記（通常は空欄） |

---

## ページ本文テンプレート

```markdown
## 基本情報

| 項目   | 内容       |
| ---- | -------- |
| 日時   | [日時]     |
| タイトル | [タイトル]   |
| 参加者  | [参加者]    |
| MEMO | 喫緊の問題など  |

---

## サマリー

[Cogno notetakerが生成したサマリーをそのままコピー]

---

## 決定事項

- [決まったこと]

---

## タスク（このミーティングで作成されたタスク）

[タスクがある場合] - [タスク内容] — [担当者] — [期限]
[タスクがない場合] - このミーティングではタスクは作成されませんでした

---

## To Do

- [ ] [次回までにしなければならないこと]

---

## メール提案

**件名:** [MTG名]のお礼とご確認

---

[相手の名前]様

本日はお忙しい中、お時間をいただきありがとうございました。
改めて、本日ご確認いただいた内容を共有させていただきます。

■ 決定事項

- [決定内容]

■ To Do

- 【[相手の名前]様】[相手のTo Do]
- 【弊社 [担当者]】[こちらのTo Do]

[次回MTG情報があれば記載]

引き続きよろしくお願いいたします。
```

## 自動転記スクリプトの使い方

```bash
export COGNO_API_TOKEN="Bearer <トークン>"
export COGNO_WORKSPACE_ID="<ワークスペースID>"
export NOTION_API_TOKEN="secret_<トークン>"

# テスト: 最新1件だけ転記（書き込みなし）
python scripts/sync_meetings_to_notion.py --limit 1 --dry-run

# テスト: ペイロード JSON を確認する
python scripts/sync_meetings_to_notion.py --limit 1 --dump-payload --dry-run

# 本番: 新規ミーティングのみ転記（既存スキップ）
python scripts/sync_meetings_to_notion.py

# 本番: 最新1件だけ転記（動作確認用）
python scripts/sync_meetings_to_notion.py --limit 1
```
