# 会議録テンプレート

> このテンプレートは Cogno notetaker が記録したミーティングを
> Notion の会議録データベースへ転記する際の標準フォーマットです。

---

## Notion データベースフィールド対応表

| フィールド | 型 | 内容 | 例 |
|---|---|---|---|
| **Title** | title | ミーティング名 | `営業定例（新井さん）` |
| **Date** | date | 開催日（YYYY-MM-DD） | `2026-08-21` |
| **Member** | rich_text | 参加者（読点区切り） | `新井康太、石原俊` |
| **MEMO** | rich_text | 要約（TLDR・2000文字以内） | `CRチェッカー受注見込み、…` |

---

## ページ本文構成

Cogno の summary データを以下の構成でページ本文に展開します。

```
[TLDR段落]
タバコ関連事業の本林社へのコンサル提案、ペリクルス・東宝インターナショナルの
アポ確定、CRチェッカー受注進行などの営業案件を確認。…

## 議事内容

- 新井さん来週アポで、タバコ関連事業(喫煙所・喫煙カフェ・EC)を運営する…
- ペリクルス(木曜)・東宝インターナショナル(金曜)のアポが確定。…
- …
```

## 手動転記手順（スクリプト不使用の場合）

1. Cogno の「ミーティング」タブで対象ミーティングを開く
2. TLDR と箇条書きをコピーする
3. Notion の会議録データベースを開く
   - URL: `https://app.notion.com/p/7d34edb50c364684900e83ef635d4e81`
4. **新規ページを追加**（最新が一番上になるよう並び替え）
5. 以下を入力する:
   - **Title**: ミーティング名（Cogno のタイトルをそのまま使用）
   - **Date**: 開催日（`YYYY-MM-DD` 形式）
   - **Member**: 参加者名（カンマまたは読点区切り）
   - **MEMO**: TLDR テキスト（2000文字以内）
6. ページ本文に箇条書きを貼り付ける

## 自動転記スクリプトの使い方

```bash
# 環境変数を設定
export COGNO_API_TOKEN="Bearer <あなたのトークン>"
export COGNO_WORKSPACE_ID="<ワークスペースID>"
export NOTION_API_TOKEN="secret_<あなたのトークン>"
export NOTION_DATABASE_ID="d1f19bb4-5186-4b35-a534-076bdd37a4e1"

# 既存ページはスキップして新規ミーティングのみ転記
python scripts/sync_meetings_to_notion.py

# 書き込まずに対象一覧を確認（テスト）
python scripts/sync_meetings_to_notion.py --dry-run

# 参加者情報も取得する（処理が遅くなる）
python scripts/sync_meetings_to_notion.py --fetch-detail
```

## 品質チェックリスト

転記後に以下を確認する。

- [ ] ミーティング名が正確に転記されている
- [ ] 日付が `YYYY-MM-DD` 形式で正しい
- [ ] MEMO 欄に要約が入っている（要約なし会議は空欄で OK）
- [ ] 本文の箇条書きが文脈通りに読める
- [ ] 個人情報・機密情報が含まれていない場合は「なし」と明記
- [ ] 最新のミーティングが一番上に来ている

---

## 注意事項

- **要約なしミーティング**: MEMO・本文は空のままで転記する（削除・省略不可）
- **タイトルが「（タイトルなし）」**: 開催日と参加者からタイトルを補完する
- **重複作成防止**: スクリプト実行時は `--skip-existing` フラグ（デフォルト有効）で
  同名タイトルを自動スキップする
- **Notion 書き込み上限**: 1 リクエストあたり 2000 文字。それ以上は切り捨て
