# shushushu 監視カメラ導入計画

> 作成日: 2026-08-28  
> タスク: #6555  
> 目的: 無人店舗での酒類提供とセキュリティ確保のためのカメラシステム設置

---

## 1. 導入の背景と目的

shushushu は無人で酒類を提供する店舗形態を採用しているため、以下の課題に対応するためカメラシステムを導入する。

| 課題 | 対応 |
|---|---|
| 年齢確認（未成年への販売防止） | 入店・購入時の顔・行動記録 |
| 万引き・不正行為の抑止 | 店内全体の常時録画 |
| 設備・商品の保護 | 入退店ログと映像の突合 |
| トラブル発生時の証拠保全 | クラウド録画による長期保存 |

---

## 2. 設置場所と台数

| 設置箇所 | 台数 | 用途 |
|---|---|---|
| 入口（外向き） | 1台 | 入退店記録・来客の顔認識 |
| レジ・決済端末付近 | 1台 | 購入行動の記録 |
| 酒棚エリア全体 | 2台 | 商品取り扱い状況の監視 |
| 店内広角（バックカメラ） | 1台 | 死角なし全体把握 |
| **合計** | **5台** | |

---

## 3. 推奨カメラシステム

### 機器選定基準

- **夜間撮影対応**（IR 赤外線搭載）— 閉店後・深夜も鮮明な映像
- **広角レンズ**（110°以上）— 少ない台数で広範囲をカバー
- **クラウドストレージ連携**— 端末盗難時にも証拠映像を保全
- **遠隔モニタリング**— スマートフォンからリアルタイム確認
- **動体検知アラート**— 不審行動を即時通知

### 推奨製品（例）

| 製品 | 特徴 | 想定単価 |
|---|---|---|
| Reolink RLC-810A（4K） | PoE接続・夜間カラー・動体検知 | 約15,000円 |
| TP-Link Tapo C320WS | Wi-Fi・クラウド録画・アプリ操作 | 約7,000円 |
| Axis P3245-V | 業務用・耐久性高・詳細分析機能 | 約60,000円 |

> 予算・運用規模に応じて選定。まずは TP-Link Tapo など低コストから試験導入も可。

---

## 4. 録画・保存ポリシー

| 項目 | 方針 |
|---|---|
| 録画方式 | 常時録画 + 動体検知録画 |
| 保存期間 | 最低 **30日間**（酒類販売法の記録義務を考慮） |
| 保存場所 | ローカル NVR（ネットワークビデオレコーダー）＋クラウドバックアップ |
| アクセス権限 | 管理者（利春、岩壁さん）のみ閲覧可 |
| データ暗号化 | 保存・転送時ともに暗号化必須 |

---

## 5. 法令・コンプライアンス対応

### 掲示義務

- **「防犯カメラ設置中」の掲示**を入口と店内に設置（個人情報保護法の透明性原則）
- 撮影範囲が店外公道に及ぶ場合は目的・管理者を記載した掲示が必要

### 酒類販売との関係

- 酒税法・未成年者飲酒禁止法の遵守を記録で補強
- 購入記録と映像の突合ができる体制を整える

### プライバシー保護

- 映像は**上記目的以外に使用しない**ことを内規で明文化
- 映像の外部提供は**法令に基づく開示請求時のみ**
